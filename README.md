# Multi-Label Emotion Inference Engine

## Overview

The Multi-Label Emotion Inference Engine is a natural language processing application that identifies multiple emotions expressed within a single piece of text. Unlike traditional sentiment analysis, which predicts a single sentiment, the system recognizes multiple co-occurring emotions to provide a richer understanding of user-generated content.

---

## Features

* Multi-label emotion classification
* Supports prediction of **12 distinct emotion categories**
* Fine-tuned large language model using parameter-efficient training
* Processes social media and short-form text
* Automated emotion annotation pipeline

---

## Tech Stack

* Python
* PyTorch
* Hugging Face Transformers
* Gemma 2B
* LoRA (PEFT)

---

## Dataset

* Training dataset: **7,000** labeled text samples
* Test dataset: **3,000** labeled text samples

---

## Results

* Achieved an **F1-score of 75%** on the test set
* Automated annotation of **10,000** social media samples
* Achieved approximately **80% schema compliance** during automated labeling
